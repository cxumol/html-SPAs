Unicode Escape (\uXXXX) Encoder/Decoder

This tool converts text to \uXXXX Unicode escape sequences (used in JavaScript, JSON, etc.) and decodes such sequences back into text. It handles characters including those outside the Basic Multilingual Plane (e.g., emojis) by encoding their surrogate pairs.

The decoder handles strings containing mixed \uXXXX sequences and literal characters. For example, an input like \uff08\u672c\u7ae0完\uff09 will be decoded as （本章完）, where 完 is treated as a literal character if it's not part of a valid 4-digit hex escape sequence.
